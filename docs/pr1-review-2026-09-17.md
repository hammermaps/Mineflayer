## Live server and remaining limits

The running local server advertises Paper 26.3, protocol 777. Native client data in this branch target 26.2, protocol 776; there is no native 26.3 dataset. The short connection attempt was rejected as an outdated client before login or gameplay.

After ViaVersion installation, the same check was still rejected. The server log identified ViaVersion 5.11.0 and ViaBackwards 5.12.0-SNAPSHOT; ViaBackwards explicitly requires ViaVersion 5.12.0 or newer and disabled itself. Consequently there is no successful 26.3 gameplay validation for this integration. Protocol translation, if configured successfully later, must be reported separately from native 26.3 support. The complete real-Minecraft external suite was not run against this mismatched server.

A later server restart still logged ViaVersion 5.11.0 and `Server version has not been loaded yet, cannot register additional listeners`; updating the live translation layer is separate from this PR integration.

`npm audit --omit=dev` reports five moderate affected runtime packages, stemming from UUID dependencies in the authentication chain, with no offered automatic fix; zero high/critical runtime findings. Including development tooling, installation reported thirteen affected packages (four high). The native dependency pins remain unchanged; this integration does not claim dependency vulnerability remediation.
